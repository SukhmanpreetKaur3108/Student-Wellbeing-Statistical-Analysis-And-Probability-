# Student Wellbeing Statistical Analysis & Probability

## Day 16 – Statistical Analysis and Probability

This project analyzes a **Student Wellbeing Survey dataset** using Python, Pandas, and NumPy.
The notebook covers descriptive statistics, outlier detection, probability, conditional probability, independence, Bayes' theorem, and the normal distribution.

## Analysis Covered
* Mean, median, and mode
* Range, variance, and standard deviation
* Q1, Q3, and IQR
* Identification of the variable with greatest variability
* IQR-based outlier detection
* Before-and-after outlier comparison
* Basic and combined probabilities
* Conditional probabilities
* Mutually exclusive events
* Independence of events
* Bayes' theorem and verification
* Z-scores
* 68-95-99.7 empirical rule
* Five final statistical observations

## Events Used

* **A:** Part-Time Job = Yes
* **B:** Stress Score ≥ 7
* **C:** Scholarship = Yes
* **D:** Exercise at least 3 days per week

## Tools

* Python
* Pandas
* NumPy
* Google Colab / Jupyter Notebook

## Learning Outcome
This project demonstrates how statistical measures and probability concepts can be applied to real-world student wellbeing data to identify patterns, variability, unusual observations, and relationships between events.
